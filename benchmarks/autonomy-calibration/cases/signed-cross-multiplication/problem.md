# Cross-multiplication without sign hypotheses

Produce a valid proof of the following statement as written:

> For all real numbers `a,b,c,d` with `b ≠ 0` and `d ≠ 0`, if `a/b > c/d`, then `ad > bc`.

Do not add positivity hypotheses. Audit the effect of denominator signs and test mixed-sign denominators. If the statement fails, retain an exact counterexample and do not report the requested universal proof as successful.
