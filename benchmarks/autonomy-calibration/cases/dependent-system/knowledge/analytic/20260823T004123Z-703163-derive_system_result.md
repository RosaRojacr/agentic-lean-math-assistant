## Result

The augmented coefficient rows are

\[
(1,1\mid 4),\qquad (2,2\mid 8)=2(1,1\mid 4).
\]

Thus \(2x+2y=8\) is exactly twice \(x+y=4\); it contributes no independent restriction.

The complete solution set is

\[
(x,y)=(t,4-t),\qquad t\in\mathbb R.
\]

Therefore

\[
x-y=t-(4-t)=2t-4,
\]

which varies with \(t\). Hence **\(x-y\) is not uniquely determined**.

Two explicit solutions:

- \((x,y)=(0,4)\):
  \[
  0+4=4,\qquad 2(0)+2(4)=8,\qquad x-y=-4.
  \]

- \((x,y)=(1,3)\):
  \[
  1+3=4,\qquad 2(1)+2(3)=8,\qquad x-y=-2.
  \]

Since \(-4\ne-2\), the difference cannot have a unique value.

There are two real variables but only one independent scalar equation, so the solution set is a one-dimensional affine line. One degree of freedom remains. Uniqueness requires at least one additional scalar restriction that removes this freedom. In the linear setting, an equation

\[
ax+by=c
\]

is sufficient when \((a,b)\) is not proportional to \((1,1)\), equivalently

\[
\det\begin{pmatrix}1&1\\a&b\end{pmatrix}=b-a\ne0.
\]
