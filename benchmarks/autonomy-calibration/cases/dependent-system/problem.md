# Determine a quantity from a linear system

Real numbers `x` and `y` satisfy

\[
x+y=4,\qquad 2x+2y=8.
\]

Report one exact numerical value for `x-y`, justified by these equations alone. Check whether the equations are independent before eliminating variables. Do not add an unstated sign, integrality, ordering, optimization, or normalization condition, and do not present a parametric family as the requested numerical value.
